# Modelos de Planilhas Excel

## modelo-notas.xlsx
Use para importar notas em lote.

Formato:
- Coluna A: Nome do Aluno
- Colunas B+: Nome da Avaliação (AV1, AV2, etc)

Preencha as notas (0.0 a 10.0) e faça upload na tela de lançamento.

## modelo-frequencia.xlsx
Use para importar frequência em lote.

Formato:
- Coluna A: Nome do Aluno  
- Coluna B: Data da Aula (formato: DD/MM/AAAA)
- Coluna C: Presença (P = presente, F = falta)

IMPORTANTE:
- Os nomes devem corresponder aos alunos cadastrados
- O sistema faz busca aproximada (primeiro + último nome)
- Notas podem usar vírgula ou ponto decimal
